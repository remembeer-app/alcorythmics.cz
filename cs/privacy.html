Zásady ochrany osobních údajů

Kdo web provozuje

Web alcorythmics.cz provozuje společnost Alcorythmics s.r.o., IČO 29927421, se sídlem Bezručova 4201, 430 03 Chomutov, Česká republika. Kontaktovat nás můžete na info@alcorythmics.cz.

Co tento web sbírá

Jde o statický web. Neukládá žádné cookies, nepoužívá analytické ani sledovací skripty a neobsahuje žádné formuláře. Jeho prostřednictvím nesbíráme žádné osobní údaje.

Služby třetích stran

Web je hostován na GitHub Pages, službě společnosti GitHub, Inc. Při otevření stránky odešle váš prohlížeč technické údaje, například vaši IP adresu, na servery GitHubu, aby mohla být stránka doručena. GitHub může tyto údaje uchovávat v serverových protokolech. Viz GitHub General Privacy Statement.

Web načítá písmo Inter ze služby Google Fonts společnosti Google LLC. Váš prohlížeč si soubory písma vyžádá ze serverů Googlu, přičemž dojde k přenosu vaší IP adresy. Viz Zásady ochrany soukromí Google.

Pokud nám napíšete

Pokud nám pošlete e-mail, zpracováváme osobní údaje, které v něm uvedete, obvykle jméno a e-mailovou adresu, pouze za účelem odpovědi na vaši zprávu. Korespondenci uchováváme po dobu nezbytnou k vyřízení vašeho požadavku a případné navazující komunikace a poté ji mažeme.

Vaše práva

Podle obecného nařízení o ochraně osobních údajů (GDPR) máte právo na přístup ke svým osobním údajům, na jejich opravu nebo výmaz, na omezení zpracování, právo vznést námitku a právo podat stížnost u Úřadu pro ochranu osobních údajů. Pro uplatnění svých práv nás kontaktujte na info@alcorythmics.cz.

Rozsah

Tyto zásady se vztahují pouze na tento web. Naše aplikace mají vlastní informace o ochraně osobních údajů.
